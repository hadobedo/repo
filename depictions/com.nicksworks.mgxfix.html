MGXFix

Nick's Works · iOS 15+

Makes the 8BitDo Ultimate MGX work as a normal game controller.

How it works

iOS already pairs the MGX as a BLE HID device and matches it in the GameController database by VID/PID, but skips its mapping on a personality version check:

Personality definition requires version '11.4.7'
did not find a compatible personality

The MGX mapping ships in a downloaded GameController database asset newer than the running GameControllerFoundation, which is why iOS 18.5 added support.

MGXFix patches the compatibility field and selects the Default personality in memory as the plists load. Nothing on disk is modified.

Notes

  • Only GameControllerConfigService is hooked.
  • Applies on the next controller connect; no respring needed.
  • Verified on iOS 17.1.1 (iPhone 13 Pro, roothide).
